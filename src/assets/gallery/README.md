Add your brother's food photos in this folder to publish them in the gallery.

Supported formats:
- .jpg
- .jpeg
- .png
- .webp
- .avif

Example filenames:
- tuna-ceviche.jpg
- tasting-menu-dessert.webp
- villa-dinner-table.png

The site will automatically show the images in `src/assets/gallery` during development and after build.
If this folder has no image files, the page uses temporary placeholder photos.
